# Student Performance Analysis & Early-Warning Insights

## About the Project
This is a Data Science project that analyses the academic performance of 100 students using a synthetic dataset.

## Objectives
- Analyse student attendance.
- Understand study hours and final scores.
- Compare subject-wise average marks.
- Categorize students based on performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## How to Run
1. Install Python.
2. Install required libraries:
   `pip install pandas numpy matplotlib`
3. Run the project:
   `python main.py`

## Dataset
The project uses 100 synthetically generated student records.

## Disclaimer
This dataset is synthetic and does not contain real student information.
